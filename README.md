# WPS Word Skill

让 Agent 在真实 Windows WPS 文字中创建、读取、编辑、排版和交付 Word 文档。Agent 根据需求选择操作、查询所需 schema、提交 JSON Task，并依据 Task Response 报告结果。

## 能力

- 新建或打开指定文档，编写标题、段落和正文。
- 设置字号、中文/西文字体、强调、对齐、缩进和行距。
- 查找、替换或删除文字，按定位范围修改内容。
- 插入表格和图片，设置页眉页脚、页面方向、页边距及分页/分节。
- 保存、另存 DOCX、导出 PDF，并返回实际文件路径。

提供 14 个 Action，完整用途和请求流程见 [SKILL.md](wps-word/SKILL.md)。一个 Task 处理一个明确文档；执行层负责参数校验、结果引用、原生回读验证和资源释放。失败或结果不确定时停止后续操作，保留已发生的效果；已提交请求可查询持久回执。

## 安装与使用

需要 Windows、Python 3.8+、已安装并注册 `KWPS.Application` 的 WPS 文字，以及已登录的桌面会话。使用系统 Windows PowerShell 和 .NET/WPF，无第三方 Python 包依赖。

1. 将完整 `wps-word/` 文件夹复制到 Agent 支持的 Skill 目录。
2. 选择 `wps-word`，直接描述文档需求。
3. 保存或导出时提供实际绝对路径，输出父目录需已存在。

例如：

> 新建一份约 300 字的内部项目启动通知。项目名“星河知识库”，启动日为 2026 年 10 月 12 日，参与部门为研发、运营、客服；目标是统一常见问题答案，首期四周。包含一个标题和三段正文，排版整齐。保存为 C:/Documents/星河知识库启动通知.docx。

请将示例输出路径换为本机实际路径。未要求保存时，文档保留在 WPS 中，不自动保存。

安装检查，不启动 WPS：

```text
python verify_package.py
python wps-word/scripts/schema.py createDocument writeContent saveAs
```

查看 Action Index：

```text
python wps-word/scripts/word.py --app word --index
```

## 验证结果

已进行 **20 个 Agent 端到端场景**的测试，以及多轮直接 JSON → Task Client → WPS 的执行层回归。

| 测试 | 范围与结果 |
| --- | --- |
| Agent 端到端 | E01–E20 共 20 个场景；历史记录中 20/20 场景的最终修改或输出 Task 成功。 |
| 端到端问题用例复测 | 上述场景中的 E03、E10、E12、E19 修正后重新测试，4/4 Task、20/20 Action 首次成功。4 例是 20 个场景的子集，不另计为新增场景。 |
| 基础执行回归 | 独立重跑 18 例，18/18 Task、80/80 Action 及预期响应检查通过。 |
| 三阶段统一执行回归 | 基础 18 例＋进阶 8 例＋复杂文字格式 12 例，共 38/38 Task、226/226 Action 成功；其中 36/38 额外响应断言通过。该轮人工粗审已由用户确认通过。 |
| 指纹与字体专项 | 指纹原生场景 4 例、正式 Task Client 场景 5 例通过；XML 解析断言 16 项、Windows 字体比较断言 13 项通过。 |
| 最近一次执行回归 | E10/E12 完整请求：2/2 Task、10/10 Action 成功，原输入路径回执查询一致。 |

20 例历史端到端记录包含路径占位符未展开、失败后重新提交等情况，因此“最终输出 Task 成功”不表示 20 例在统一条件下首次全部通过，也不代替逐项人工验收。四例复测验证了修正后的指定场景。不同轮次有重复用例，不合并成一个扩大后的样本总数。

三阶段执行回归的 Task 内部处理平均约 **2.36 秒**，38 个 Task 合计 89.60 秒；除新建/打开外，其余 188 次 Action 平均约 **162 毫秒**。这些是该批次执行层观测，不包含 Agent 编排时间，也不是性能承诺。

## 已知限制

目前验收环境为 Windows WPS。部分分节场景的分页计数与测试预期存在口径差异；图片 contain 布局的回读尺寸可能与严格尺寸预期不同。这两项是上述 38 例中额外响应断言的保留差异。

## 发行内容

`wps-word/` 包含 Skill 说明、宿主发现信息、查询/提交脚本、schema 和必要运行时，复制整个目录即可安装。根目录的 README、发行说明、校验脚本和许可证用于安装与版本管理。更新时整体替换 Skill 目录。
