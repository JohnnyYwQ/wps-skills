# Domain docs

This repository uses a single domain context.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read the relevant accepted decisions in `docs/adr/`.
- Treat a superseded ADR as history rather than the current decision.

## Vocabulary

Use the canonical terms from `CONTEXT.md` in issues, specifications, tests, and implementation notes. Do not substitute a term listed under `_Avoid_`.

## Conflicts

If proposed work contradicts an accepted ADR, surface the conflict explicitly and resolve it through domain modeling before implementation.
