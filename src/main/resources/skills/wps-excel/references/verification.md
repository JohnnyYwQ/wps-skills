# 验证和持久化

1. 对照用户要求检查修改响应中的实际单元格值、公式和请求的格式；公式计算后检查错误码与预期结果。必要时再次 `readRange`。
2. `readRange` 是有界矩形读取，不代表整张表或整个工作簿都已检查。未知区域和未检查的公式依赖不能报告为已验证。
3. 需要保存时显式 `save`。它仅保存绑定时的 `.xlsx` 路径，检查确切工作簿、非空文件、格式和 WPS Saved 状态。WPS 原位保存替换文件时，保留路径及原文件占用并取得新文件身份占用；不另存为。外部 Save As 或非本次保存造成的文件身份变化会终止可用绑定。
4. 检查保存响应 artifact.path、format、sizeBytes 和 documentState。Session 清理不会补做保存，也不关闭用户工作簿。

发生部分写入或响应丢失时不重放修改。Session 可用时只读检查当前区域；若 Session 已结束，先明确原文档是否仍可安全绑定，不通过换路径或解除 Quarantine 继续执行。
